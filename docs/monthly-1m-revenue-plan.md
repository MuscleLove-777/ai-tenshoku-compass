# 月100万円サイト設計

## 方針

PV型ではなく、高単価CV型で作る。

- 転職相談
- フリーランス案件相談
- AIスクール相談
- 退職代行から転職への復帰導線

## 逆算

月100万円の一例:

- 月間訪問者: 50,000
- CTAクリック率: 10%
- 成約率: 5%
- 1件平均報酬: 40,000円
- 推定: 50,000 x 10% x 5% x 40,000 = 10,000,000円

現実運用では承認率を考慮し、表示回数、クリック、発生、承認を分けて追う。
